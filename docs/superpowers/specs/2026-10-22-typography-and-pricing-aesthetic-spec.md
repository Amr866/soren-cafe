# سند نقشه راه و مشخصات بصری: تایپوگرافی مدرن و سیستم قیمت‌گذاری (Peyda / Yekan Bakh + تومان مینیاتوری)

- **وضعیت:** تصویب‌شده برای فاز بعد (Ready for Upcoming Sprint - Do Not Implement Yet)
- **هدف:** ارتقای تایپوگرافی و ارقام اپلیکیشن کافه سورن به سبک مدرن و هندسی (الهام‌گرفته از دیجی‌کالا و بلوبانک)، با تلفیق فونت **پیدا (Peyda)** یا **یکان‌باخ (Yekan Bakh)** و نشان مینیمال «تومان».

## ۱. چشم‌انداز دیزاین (Design Vision)

کافه‌های موج سوم و تخصصی (Specialty Coffee) به جزییات بصری، سرامیک‌ها و مینیمالیسم فضای داخلی اهمیت زیادی می‌دهند. در عین حال، وضوح و خوانایی قیمت‌ها و ارقام باید مانند پیشرفته‌ترین اپ‌های فین‌تک و ایکامرس ایران (نظیر دیجی‌کالا و بلوبانک) مطمئن، هندسی و بی‌درنگ در چشم بنشیند.

### ستون‌های اصلی رویکرد انتخابی (Option 2):
1. **تایپوگرافی هندسی و فشن (Geometric Modern):** استفاده از تایپ‌فیس **پیدا (Peyda)** یا **یکان‌باخ (Yekan Bakh)** به‌جای تایپ‌فیس‌های عمومی.
2. **اعداد فارسی مونواسپیس/تبولار (Tabular Persian Numerals):** ارقام کاملاً فارسی با ضخامت بولد، قوس‌های هندسی و فواصل منظم که اسکن چشمی منو را فوق‌العاده سریع می‌کند.
3. **میکرو-گلیف «تومان» (Digikala-Style Compact Toman):** حذف کلمه طولانی «تومان» از خط اصلی متن و تبدیل آن به یک نشان مینیاتوری جمع‌وجور در کنار رقم.
4. **حفظ هویت لمسی و گرم کافه:** اعمال این المان‌های مدرن روی پس‌زمینه سرامیکی (`#faf7f2`) با رنگ جوهر اسپرسو (`#1c130d`) و تمبرهای لمسی، بدون افتادن در دام ظاهر خسته‌کننده فروشگاه‌های دیجیتال.

## ۲. مشخصات تایپ‌فیس (Typography Specifications)

### ۲.۱. فونت اصلی: پیدا (Peyda) / یکان‌باخ (Yekan Bakh)
* **دلیل انتخاب:** بر خلاف فونت‌های تجاری حجیم، فونت‌های «پیدا» و «یکان باخ» کاراکترهایی بسیار مدرن، کمی مربعی با منحنی‌های دقیق و حس لوکس دارند؛ مشابه آنچه در برندهای طراحی، کافه‌های بین‌المللی و اپلیکیشن‌هایی چون بلوبانک دیده می‌شود.
* **وزن‌های مورد نیاز:**
  * `Regular (400)`: توضیحات ریز، یادداشت‌های طعم‌شناسی و بادی تکست ثانویه
  * `Medium (500)`: متن آیتم‌های منو و دکمه‌ها
  * `SemiBold (600)`: عناوین دسته‌بندی‌ها و سرتیترها
  * `Bold (700) / ExtraBold (800)`: اختصاصی برای قیمت‌ها و ارقام کلیدی

```css
/* نمونه تعریف در style.css */
@font-face {
  font-family: 'Peyda';
  src: url('../fonts/Peyda-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: 'Peyda';
  src: url('../fonts/Peyda-Bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
```

### ۲.۲. رفتار ارقام (Numbers & Numerals)
* ارقام باید ۱۰۰٪ فارسی باشند (`۰ ۱ ۲ ۳ ۴ ۵ ۶ ۷ ۸ ۹`).
* فعال‌سازی ویژگی اعداد جدولی در CSS:
  ```css
  font-variant-numeric: tabular-nums;
  font-feature-settings: "tnum" 1;
  ```
* فاصله جداکننده هزارگان (کاما فارسی یا ویرگول ریز) باید با فاصله ظریف تنظیم شود تا ارقام پیوسته و بدون پرش خوانده شوند (`۱۵۰٬۰۰۰`).

## ۳. معماری نشانگر قیمت و گلیف تومان (Price Architecture)

در دیجی‌کالا و سیستم‌های مدرن، قیمت به عنوان یک کامپوننت دوتکه طراحی می‌شود:
1. **رقم اصلی (The Amount):** سایز بزرگ، وزن Bold/Black، فونت هندسی.
2. **واحد تومان (The Toman Unit):** سایز کوچک (۱۰ تا ۱۱ پیکسل)، با اوپاسیتی یا رنگ ملایم‌تر، چسبیده به گوشه یا زیر رقم تا عرض بی‌مورد اشغال نکند.

### ساختار HTML پیشنهادی:
```html
<div class="soren-price-lockup">
  <span class="price-value">۱۵۰٬۰۰۰</span>
  <span class="toman-badge">تومان</span>
</div>
```

### استایل CSS پیشنهادی:
```css
.soren-price-lockup {
  display: inline-flex;
  align-items: baseline;
  gap: 4px;
  direction: rtl;
  font-family: 'Peyda', 'Yekan Bakh', 'Vazirmatn', sans-serif;
}

.soren-price-lockup .price-value {
  font-size: 1.15rem;
  font-weight: 800;
  color: var(--terrace-text, #1c130d);
  letter-spacing: -0.02em;
  font-variant-numeric: tabular-nums;
}

.soren-price-lockup .toman-badge {
  font-size: 0.68rem;
  font-weight: 600;
  color: var(--terrace-text-secondary, #6e5a4d);
  line-height: 1;
  opacity: 0.85;
}
```

## ۵. چک‌لیست و مراحل گام‌به‌گام پیاده‌سازی (برای آپدیت‌های پیش‌رو)

هنگامی که زمان پیاده‌سازی این فاز فرا رسید، مراحل زیر به ترتیب اجرا می‌شوند:

- [ ] **گام ۱: آماده‌سازی فایل‌های فونت**
  - قرار دادن فایل‌های بهینه `woff2` فونت **Peyda** یا **Yekan Bakh** در دایرکتوری `frontend/fonts/`.
  - تنظیم لایسنس و دسترسی وب‌فونت.
- [ ] **گام ۲: به‌روزرسانی توکن‌های تایپوگرافی در `style.css`**

  - تعریف کلاس‌های `.soren-price-lockup` و `.toman-badge`.
- [ ] **گام ۳: تابع کمکی رندر قیمت در `frontend/main.js`**

- [ ] **گام ۴: یکپارچه‌سازی با انیمیشن تغییر قیمت (Digit Flip)**
  - هماهنگ کردن انیمیشن تغییر قیمت در شیت شخصی‌سازی با ارقام فارسی پهن‌تر فونت جدید.
- [ ] **گام ۵: تست بین دستگاهی و ارزیابی کنتراست**
  - اجرای تست‌های خودکار `verify-artisanal-frontend.mjs` جهت اطمینان از عملکرد صددرصدی روی موبایل و دسکتاپ.
